# Loom 织机 · 5 分钟现场讲稿（R6 收官）

**适用对象：** 未看过方案的值班负责人 / 技术领导  
**入口：** http://localhost:4567  
**声明：** 本收官 = **可对外演示的技术验证 demo**，≠ 生产接入批准。

---

## 固定顺序（约 5 分钟）

### 1. 开页看边界卡（30 秒）
打开页面，先指顶栏「证明 / 不证明 / 下一里程碑 / 收官」条，再展开 HowTo 里的边界卡。

**口述：**
> 这不是又一个聊天窗，也不是可上生产的自动修 bug 代理人。  
> 它证明：飞书形事件进来 → 开主工单 → **真改 sandbox 文件** → 测绿 → 假机器人回执可审计。  
> 它不证明：LLM 修复杂缺陷、真飞书 Open API、生产权限模型。

### 2. 选场景 A（15 秒）
在 HowTo「主故事场景」选 **A · calc.js 除零**。确认徽章显示 `场景 A · calc.js`。

**口述：** 主故事只有一条——运维值班群报 divide 除零。旁路（文档/日历/审批）会出简报，但不会抢主时间线。

### 3. 跑一遍飞书场景（60–90 秒）
点 **「跑一遍飞书场景」**。运行中按钮禁用；若有人连点，服务端返回 **HTTP 409 demo_locked**。

边跑边指顶栏 **「本轮发生了什么」** 五步：
1. 群@进线  
2. 开工单  
3. Worker 改 calc.js（规则补丁，非 LLM）  
4. 测绿  
5. 画廊产物  

### 4. 指时间线 → 自动弹出主产物（60 秒）
五步跑完后，结论条应类似：  
`本轮：值班群报障 → 规则补丁 calc.js → 2 测绿 → 已回执`

演示结束会 **自动打开** 主故事「缺陷修复说明」。点时间线第 5 步也可跳到该产物。

**口述：** 工场里带「主故事」徽章的那张票就是这条链；画廊主产物置顶，旁路三份简报标题互异可折叠。

### 5. 导出审计包，打开 MD 念结论（60–90 秒）
点 **「导出审计包 · MD」**，打开下载文件，按顺序念：
- 场景标签 `场景 A · calc.js`
- **五步时间线**（源码编号应为 `1.`…`5.`）
- 主故事 Ticket / 产物
- 飞书 ACK 全文（缺陷用「已修复」；简报用「已生成简报」——不许说谎）
- **收官声明**

**口述：** 证据能带走，不依赖当场还开着浏览器。

### 6.（可选）切场景 B 再跑（60 秒）
重置 → 选 **B · format.js null** → 再跑。证明不是唯一脚本路径：补丁打在 `format.js`，徽章与结论对齐 `场景 B · format.js`。

## 讲完立刻回答的三句

| 问 | 答 |
|----|----|
| 谁在用？ | 飞书值班 / 需要少盯对话、多收可审计结果的研发运维 |
| 解决哪件具体事？ | 群里报简单缺陷 → 自动开单、改文件、测绿、回执、出说明 |
| 现在能上生产吗？ | **不能。** 这是技术验证 demo；真 webhook / Open API / 权限未接 |
