连接飞书机器人

03 / 05

使用企业自建应用的机器人身份，先校验应用。此时还不会开始监听。

还没有可用的飞书应用？查看准备步骤
  1. 在飞书开发者后台创建企业自建应用，并启用「机器人」。
  2. 为消息接收配置「长连接」，订阅 im.message.receive_v1。
  3. 开通机器人消息读取、发送、群信息与附件权限；静默识别另需「获取群组中所有消息」权限。
  4. 发布应用并完成企业侧审批，再把机器人加入你要选择的群。
  5. 从「凭证与基础信息」复制 App ID 和 Secret。

向导会实际验证身份；平台权限与审批必须在飞书中完成。没有全群消息权限时，不能据此宣称静默监听可用。
