# 飞书中的个人助手入口

当前 Harness 面板运行在本机回环地址，承担开发、检查任务状态和查看本地产物的职责。保留 Harness 的 Router、Worker、稳定任务与持久化机制，日常交互通过飞书消息与卡片逐步接入。第一版仍为单个所有者的个人助手，群聊仅是明确授权的信息来源，不引入团队共享权限。

2026-11-03 已按用户选择调整为群内原线程为主、机器人私聊按需查询任务和产物；暂不推进飞书工作台。现有机器人已接通文字查询与控制；私聊列表、已保存报告和真实 TXT 附件已验收。163 邮件已通过私聊预览、本人确认、SMTP 接收与用户收件确认，企业邮箱发信暂缓，卡片回调仍待实现。可用指令见 [使用说明](FEISHU_ASSISTANT.md)，具体状态语义见 [交互方案](FEISHU_INTERACTION.md)。

## 飞书中的入口

- 机器人：私聊、群内明确请求、原线程追加要求和结果交付。无 @ 的候选需求在 observe 模式只记录，不自动执行。
- 私聊按需查询：已接通任务列表、控制状态、已保存报告预览及 TXT 文件导出，连接同一个任务 ID；完整文件产物索引和原线程快捷跳转仍待实现。
- 明确文字控制：已接通暂停、接管及带状态版本的继续／交还。后端核验实际操作者、原线程、任务归属、消息时间和状态版本，查询不唤醒任务。交互卡片及其回调仍待接入。
- 邮件：支持飞书企业邮箱与 163，当前按用户选择切换至 163 SMTP。先支持定稿报告给本人预览、明确确认、取消及提交状态查询；服务和账号变化使旧预览失效。SMTP 服务器接收与实际收件分别记录，单次交付已通过真实验收。自动规则和附件仍待实现。
- 工作台网页应用：当前暂缓；以后需要时再提供更复杂的编辑和集中管理，不作为本版使用前提。

飞书支持在客户端打开自有网页应用及免登：[应用登录概述](https://open.feishu.cn/document/client-docs/build-login-free-system-)。身份登录和数据资源授权是不同的事情；登录成功不能自动取得所有飞书文档、聊天或其他用户任务的权限。

## 推广前需要的服务边界

1. 对外入口使用 HTTPS 与飞书身份登录，服务端建立会话并检查任务归属。当前仅供本机使用的 `/orchestrator/api` 不直接暴露公网，浏览器不保存机器人 Secret 或模型密钥。
2. 身份网关把请求映射到获授权的个人运行实例。用户的消息、任务、缓存、产物、凭据和模型会话按所有者隔离；增加第二个用户前落实 ROADMAP 的 F1，不复用当前全局 Router 作为共享记忆。
3. 网页通过稳定的产品 API 查询任务与产物，不依赖底层 Session 的内部结构。执行记录和控制状态以后台为准。只查看任务不改变执行状态。
4. 产物下载必须经过鉴权和任务范围校验，不能把任意本地路径拼成文件服务；源资料的可见范围同时约束摘要、预览、导出和群内交付。
5. 个人电脑上的文件与设备动作由本地执行端负责。若增加云端或远程设备，先补设备身份、连接保护、撤销、离线恢复和命令范围；网页应用迁移不代表已具备这些能力。

## 本轮已落地和限制

复用现有面板和任务级暂停／接管／交还。后台持久化控制状态，在工具、准备步骤和消息交付前检查；排队旧结果在交接时作废，在途操作结束后才确认交接。取消或重启后结果不明的操作保留为“待核查”，需要操作者记录实际外部结果，不能自动当作成功或重放。后台作业停止超时或子任务未释放时保持等待，可显式重试。普通查询及控制已有飞书文字入口；异常操作核查仍在本机面板，飞书控制卡片与独立网页尚未交付。

控制范围是 Harness 管理的工具调用、作业、子任务和消息队列。它不是操作系统隔离、通用设备控制权或协同编辑事务：自行脱离作业管理的进程、任意 shell 的直接外部写入及人工文件版本冲突，仍需要更严格的执行和资源网关。个人模式关闭主 Router 的 shell，Worker 仍在操作者的设备权限下工作；这不适合直接承载多个互不信任的用户或生产群的私人资料。

本轮只为已指定的测试群开启入口，保持仅所有者能发起或追加要求；其他成员的消息不能唤醒已有任务。被授权读取的群讨论仍可能作为资料进入上下文。来源过滤与提示词不是完整的跨任务信息流隔离，真实私人数据的群内交付仍待资源与目的地网关验收。
