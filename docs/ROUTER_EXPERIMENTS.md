# Router 分片实验结论

记录日期：2026-11-10。当前决策：保留单逻辑 Router 作为产品基线，后续以有界并发池作为性能对照；不因提高并发直接拆分上下文。继续先实现计算、持久状态与执行环境分离。

## 实验范围

使用实际配置的 `deepseek-v4.1-flash-1017`、合成任务、JSON Router 替身和模拟 Worker。没有接入真实群聊或生产状态，也没有运行原生 DSH Session。结果说明被测机制在小样本中的行为，不提供生产容量或业务准确率。

第一轮按线程哈希隔离上下文，并刻意将目标依赖请求投向另一分片。无索引分片既不能查询任务，也不能转交，14 次请求所需目标记录不可见。29/32 与 14/32 的差距主要反映这一信息缺口；其中安全澄清和前序暂停失败导致的恢复拒绝不能都解释为路由判断错误。该组只保留为失效对照。

## 第二轮结果

并发实验让三组收到逐字相同的任务资料，并核验实际请求哈希。三轮各 24 个事件，允许两个模型请求并发时，平均处理时间如下：

| 方案 | 平均处理秒数 | 动作和目标正确 |
| --- | ---: | ---: |
| 单 Router 串行 | 31.90 | 72/72 |
| 单逻辑 Router 加有界并发池 | 17.76 | 72/72 |
| 双全量上下文副本 | 21.11 | 71/72 |

额外模型并发可以由单逻辑 Router 消费。双全量副本出现一次模糊指代误改；同一输入的模型结果和服务时间也有波动，三次重复不足以确定一般性能排序。冻结快照和不同目标让本次并发更新可交换，不意味着当前 DSH 的同一个有状态 Session 能直接并行多个 turn。

分片实验采用固定项目归属、共享精简任务目录和一次转交。目录只含 ID、项目、标题和归属，完整版本、状态与业务字段由归属 Router 读取。所有组都能获得执行所需证据，转交回合和排队计入成本。

| 定向请求跨分片比例 | 并发池完成 | 项目双分片完成 | 并发池平均秒数 | 双分片平均秒数 |
| --- | ---: | ---: | ---: | ---: |
| 0% | 48/48 | 48/48 | 15.76 | 19.19 |
| 10% | 48/48 | 48/48 | 17.85 | 24.63 |
| 30% | 48/48 | 48/48 | 22.23 | 34.58 |
| 50% | 48/48 | 48/48 | 22.13 | 41.33 |

每档两轮，每轮 24 个模型事件；比例针对其中 20 个定向请求。36 个远端事件全部转交成功。两方案均为 192/192，没有重现第一轮的大幅差距；本实现的转交成本随跨分片比例上升。不能据此认定该转交协议已经最优，也不能将目录访问当作全文检索质量验收。

四条连续轨迹均达到预期最终状态，12 项去重、显式状态查询或旧版本保护等宿主检查通过。严格 JSON 字段分数和实际效果分开保留：恢复时不重复写入已经相同的口径，仍可得到正确结果。独立决策另按原始快照逐条重放，避免一次误改导致的版本拒绝被重复算成独立判断错误。

## 对开发路线的影响

- 优先落实短事务、持久作业、控制版本、Session 单写者与执行账本；Router 数量不代替这些约束。
- 后续性能基准同时包含串行、单逻辑 Router 加并发池、完整分片方案；保持证据可获得性和全局模型额度可比。
- 若上下文规模或真实负载要求分片，再验证任务归属、按需读取与转交。跨权限域仍执行独立授权，不因同属公司就共享完整记忆。
- 下一阶段验证应使用隔离的原生 DSH、较大上下文、持续负载、乱序／故障与权限变化。当前实验中的并发池、目录和转交尚未接入 Loom 产品。

## 复核与方法调整

原始证据在本机忽略目录 `.artifacts/experiments/router-sharding-v2-20261110/`：`plan.json`、`data/`、`calls.jsonl`、`summary.json`、`verification.json` 和 `report.html`。第一轮与方法审阅保留在 `.artifacts/experiments/router-sharding-20261110/`。这些路径不是远端仓库中已发布的附件。

第二轮主比较采用 271 次模型请求，全部调用（含预跑和作废计时）共 328 次。合批预跑曾与计时重叠，受影响的两个完整对照批次全部排除并重跑；原始调用、ID 修复映射和用量保留。随后加入并验证跨进程互斥。累计输入预算提高后，未完成轨迹按原输入哈希复用已有响应，只请求未尝试步骤，未重试失败响应。中断轨迹时间包含预算暂停，不用于速度结论。

评分的独立重放及效果核验是明确标注的补充审计，未覆盖原严格结果。模型输出预算由第一轮的 1,536 提高到 6,144 token，因此两轮分数变化不能全部归因于分片机制。全部协议调整见第二轮 `protocol-amendment-01.json` 至 `protocol-amendment-04.json`。
